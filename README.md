# Robust Multibasin Geometry

Applied-mathematics research project on robust extinction/survival basin geometry in fractional dynamical systems.

**Core question:** how do extinction and survival basins, separators, basin-relative persistence, and bistability behave under simultaneous uncertainty in ecological parameters, fractional orders, and memory kernels?

This repository is an original-research project descended from the theorem-level mapping in `maximilianolucius/fractional-stability-front`.
